## Criterio aplicado en la revisión

1. **Herramienta ≠ tema evaluado**: si una operación (traspuesta, producto vectorial, continuidad de un polinomio...) aparece solo como paso intermedio para llegar a otra cosa (discutir un sistema, calcular un área, aplicar Rolle), no se etiqueta como tema propio.
2. **"Resolver un sistema" ≠ "método de Gauss"**: los problemas verbales de álgebra que no exigen un método concreto se marcan con confianza `media` y una nota explícita de limitación de catálogo, en vez de forzar una etiqueta de precisión que el enunciado no respalda.
3. **"Discutir según un parámetro" + "resolver para un valor"**: cuando un ejercicio tiene ambos apartados por separado (con pesos de puntuación distintos), las dos etiquetas (`teorema-de-rouche-frobenius-discusion` + `analisis-de-sistemas-por-el-metodo-de-gauss`) son correctas y de confianza `alta`, no `media`.
4. **Probabilidad condicionada ≠ Bayes**: solo se etiqueta `teoremas-de-la-probabilidad-total-y-de-bayes` cuando hay una partición real del espacio muestral o una probabilidad a posteriori genuina — no cuando el ejercicio es manipulación algebraica de P(A∪B), P(A∩B), complementarios e independencia (eso es `algebra-de-sucesos-y-tipos-de-experimentos`).
5. **μ y σ dados ≠ tema de parámetros**: `parametros-de-una-distribucion-media-varianza-y-desviacion-tipica` solo se mantiene cuando el ejercicio pide calcular/derivar esos parámetros, no cuando vienen dados en el enunciado de una normal.
6. **Varias etiquetas correctas pueden ser `alta`**: la confianza `media` se reserva para ambigüedad real (técnica no determinable, o límite de catálogo), no simplemente por tener más de un `topic_slug`.
